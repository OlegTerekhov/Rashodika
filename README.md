# Расходика

Бесплатное веб-приложение для учёта материалов, процедур и прибыли мастера.

## Возможности
- Расчёт цены единицы материала по цене и объёму упаковки.
- Запись процедур с клиентом, датой, ценой и использованными материалами.
- Расчёт расходов, прибыли и маржинальности.
- История процедур, фильтры и поиск.
- Экспорт журнала в CSV.
- Установка как PWA и базовая работа офлайн после первого открытия.

## Запуск
Публикуется как статический сайт на GitHub Pages. Все пути относительные, чтобы поддерживать публикацию в подпапке репозитория.

## Важно о данных
На текущем этапе данные хранятся в localStorage браузера и не синхронизируются между устройствами. Очистка данных браузера может привести к потере записей. Не используй реальные персональные данные клиентов до настройки резервного копирования/синхронизации.
